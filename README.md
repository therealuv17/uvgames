# 🎮 UV Games Collection

A collection of fun web-based games including race car games and a dinosaur jumping game!

## 🎯 Games Included

### 🏎️ Race Car Game (2D)
- **File**: `index.html`
- Classic top-down racing game
- Avoid obstacles and score points
- Use arrow keys or WASD to control

### 🦕 Dinosaur Game
- **File**: `dino-index.html`
- Jump over cactuses
- High score tracking
- Press SPACE or UP ARROW to jump

### ⚡ SPYDERPUNK RACER PRO (3D)
- **File**: `race3d-pro-index.html`
- Cyberpunk-themed 3D racing game
- Features:
  - Curved tracks
  - Drifting mechanics
  - Boost system
  - Multiple stages
  - Obstacles to avoid
  - Background music support

### 🏎️ 3D Race Car Game (Original)
- **File**: `race3d-index.html`
- Original 3D racing game with opponents

## 🚀 How to Play

1. Open any HTML file in your web browser
2. Click "Start Game" or "JACK IN"
3. Follow the on-screen controls

## 🎵 Adding Music

To add background music to SPYDERPUNK RACER PRO:
1. Download your music file (MP3 format)
2. Save it as `mood.mp3` in this folder
3. The game will automatically play it

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js (for 3D games)
